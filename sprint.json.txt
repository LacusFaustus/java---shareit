Create 2 users with same email - 409 Conflict или 400 Bad Request

Create user with invalid email - 400 Bad Request

User update - 200 OK

User update name - 200 OK

User update email - 200 OK

User update with existing email - 409 Conflict

Get user - 200 OK

User delete - 200 OK или 204 No Content

Item update without X-Sharer-User-Id - 400 Bad Request (или 500)
